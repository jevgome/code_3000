# Statement of Security

This file outlines the intent and procedures implemented to secure this repository.

## Intended Users

I (jevgome) am the sole contributor intended to commit any code or data in this repository. In addtion, the professor and any students in this course are the intended users of this repository.

## Security Risk Assessment

The repository does not contain any personal or sensitive data, so there is very low security risk. If this repository fell into the wrong hands, the malicious user would not be able to do anything of significant impact. The only concern would be unauthorized knowledge of the contents of this repository, which could leak answers to the class modules.

## Security Steps Taken

This repository contains a CODEOWNERS file, ensuring that only those users listed in the file are permitted to accept changes made by outside users. There is no need for any additional security, as the risk of a security breach is low.
